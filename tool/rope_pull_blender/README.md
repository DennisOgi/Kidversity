# Rope Pull art pipeline (Blender)

Everything in `assets/rope_pull/scene/` is generated by these scripts with the
`bpy` Python module (Blender 5.0, Cycles on CPU, flat toon shading via
emission so colours stay on palette).

| Script | What it makes |
| --- | --- |
| `toon.py` | Shared helpers: toon materials, inverted-hull outlines, lathe meshes |
| `kid.py` | Builds one rigged kid (armature + IK hands/feet). Looks live in `KIDS` / `TEAMS` |
| `render_kid.py` | Poses and renders idle, pull, slip, win, lose; writes per-frame hand and foot points |
| `scene.py` | The school-field backdrop (`court.jpg`) with the same camera tilt |
| `pack.py` | Packs frames into 8-column sprite sheets (448 px cells) and `kids.json` |
| `compose.py` | Python preview of the in-app layout; also makes `hero.jpg` / `tile.jpg` |

Run (paths inside the scripts point at a scratch folder; adjust as needed):

```
python render_kid.py indigo-captain out/full/indigo-captain   # x4 kids
python scene.py out/scn
python pack.py
```

`lib/widgets/rope_arena.dart` reads `kids.json` at runtime. If you re-render the
court, copy the numbers printed by `scene.py` into `_Court` in that file.
The Teal kids are rendered facing right like Indigo and mirrored at draw time.
