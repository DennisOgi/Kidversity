# Rope Pull art pipeline (Blender)

Everything in `assets/rope_pull/scene/` is generated by these scripts with the
`bpy` Python module (Blender 5.0, Cycles on CPU, flat toon shading via
emission so colours stay on palette). The rope itself is drawn in code
(`_rope` in `lib/widgets/rope_arena.dart`), not rendered.

| Script | What it makes |
| --- | --- |
| `toon.py` | Shared helpers: toon materials, inverted-hull outlines, lathe meshes |
| `kid.py` | Builds one rigged kid (armature + IK hands/feet). Looks live in `KIDS` / `TEAMS` |
| `render_kid.py` | Poses and renders idle, pull, slip, win, lose; writes per-frame hand and foot points |
| `scene.py` | The school-field backdrop (`court.png` + `court.json`) with the same camera tilt |
| `pack.py` | Packs frames into 8-column sprite sheets (448 px cells) and `kids.json` |
| `compose.py` | Python preview of the in-app layout; also makes `hero.jpg` / `tile.jpg` |
| `sim.py` | Python port of the in-app painter, for checking poses without Flutter |

## Run it

All scratch output goes under `ROPE_PULL_WORK` (default `rp_work`). Run from
this folder with Python that has `bpy` and Pillow installed.

```bash
export ROPE_PULL_WORK=rp_work
for kid in indigo-captain indigo-partner teal-captain teal-partner; do
  python render_kid.py "$kid" "$ROPE_PULL_WORK/full/$kid"
done
python scene.py "$ROPE_PULL_WORK/scn"
python pack.py                 # palette PNGs (smallest files)
# ROPE_PULL_RGBA=1 python pack.py   # full-colour PNGs, see below
python sim.py                  # optional: preview frames
```

Then copy into the app:

| From | To |
| --- | --- |
| `$ROPE_PULL_WORK/out/*.png` and `kids.json` | `assets/rope_pull/scene/` |
| `$ROPE_PULL_WORK/scn/court.png`, saved as JPEG | `assets/rope_pull/scene/court.jpg` |

If you re-render the court, `scene.py` prints its size, pixels per metre and
ground point. Copy those numbers into `_Court` in `lib/widgets/rope_arena.dart`.
The Teal kids are rendered facing right like Indigo and mirrored at draw time.

## Palette or full colour

`pack.py` saves 256-colour palette PNGs by default (about 400 KB per kid).
Flutter's web image decoder rejects those, so on web the app decodes them
through the browser instead (`lib/widgets/rope_png_decode_web.dart`), which is
slower. `ROPE_PULL_RGBA=1` writes full-colour PNGs that every decoder accepts,
at the cost of bigger downloads.

## Memory

Each sheet is 3584 × 3136 px. On phones the app decodes the sheets at half or
three-quarter size (`ropeSheetScaleFor` in `rope_arena.dart`) and shares one
decoded copy across the lobby, match and finish screens.
